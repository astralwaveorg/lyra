# 赞助与社群

Lyra 是 MIT 许可的开源项目，所有功能都可以免费使用。赞助完全自愿，不影响功能、更新或支持优先级。

## 赞赏

如果 Lyra 帮你省下了整理曲库的时间，可以请作者喝杯咖啡。赞赏会用于维护服务器、测试设备和后续开发。

## 交流群

扫码加入 Lyra 官方交流群，反馈问题、交流部署经验。

<img src="assets/community.jpg" alt="Lyra 官方交流群" width="320">

> 群二维码有效期至 **2026-10-26**。过期后请在 GitHub Issues 中反馈，作者会更新。
> 群里不提供破解、盗版资源或付费代整理服务。

## 其他参与方式

- 提交 Bug 或功能建议：[Issues](https://github.com/astralwaveorg/lyra/issues)
- 提交代码或文档：[Pull Request](https://github.com/astralwaveorg/lyra/pulls)
- 补充部署经验、翻译、截图
- 在博客、论坛或 NAS 社区介绍 Lyra

## 致谢

感谢 MusicBrainz、AcoustID、LRCLIB，以及所有提交问题、代码和文档的贡献者。

本项目与上述服务没有隶属关系。Lyra 不托管、不分发任何音乐或歌词内容，只维护用户本地已有的文件。
