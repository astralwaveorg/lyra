# 路线图

路线图是方向，不是承诺。优先级会根据反馈和安全问题调整。

## 近期

- [ ] 完善 OGG / Opus 封面写入
- [ ] 增加英文界面
- [ ] 整理预览支持按目录树折叠和搜索
- [ ] 重复检测增加更多音频指纹来源
- [ ] 提供 Prometheus 指标
- [ ] 改进移动端的歌词逐行对比

## 中期

- [ ] 多用户与只读访客
- [ ] Webhook / 事件通知
- [ ] 对象存储与远程曲库
- [ ] 插件式元数据来源
- [ ] 更细的自动写入策略

## 已完成

- [x] FLAC / MP3 / OGG 字节级歌词写入
- [x] MusicBrainz 标签刮削与逐字段冲突处理
- [x] AcoustID 指纹兜底
- [x] 按标签整理、预览、移动和撤销
- [x] 重复音频分类、分类过滤与批量删除
- [x] 空目录清理与批量撤销
- [x] 回收站、日志、API Token、移动端适配

## 不做

- 不提供音乐下载或盗版资源。
- 不自动删除重复音频。
- 不把用户曲库上传到第三方。
- 不在后台自动移动文件。
