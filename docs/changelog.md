# 更新记录

完整记录见仓库根目录的 [CHANGELOG.md](https://github.com/astralwaveorg/lyra/blob/main/CHANGELOG.md)。

## 1.2.3

- 待审查列表支持勾选多条：行首单选、组头整组、全选本页，「写入所选（N）」按建议一次写入
- 批量写入含冲突覆盖，确认框列出补空、纠正、冲突数量；标题搜索来源不参与批量
- 单条失败不影响其余；「写入本页可补」保持只写补空与纠正的原语义

## 1.2.2

- 「无来源歌词」的「与已有歌词重复」判定不再用名字包含关系：`Love Me Do` 不会再被挂到 `ME!` 上
- 只有名字完全相同、或长的是短的前缀/后缀（艺人/版本写法）才算同一首
- 「纯音乐，请欣赏」这类占位文案不再算「已有歌词」，这类条目改标「需指定归属」
- 内嵌歌词同样算「已有歌词」，真冗余的歌词不会再留在待处理列表里

## 1.2.1

- 人工「采用并写入」会真的写入：内容相同也强制落盘，不再回一句「无需重复写入」
- 歌词预览会提示时间轴超出音频时长，让人提前换一条合适的候选

## 1.2.0

- 人工确认过的标签提案不会再被扫描带回队列
- 「链接指定条目」写入完成后标记为已定案，不再被搜索结果覆盖
- 新增「忽略」：条目移出队列且扫描不再翻它回来
- 新增「已忽略」页签与「恢复」按钮

## 1.1.1

- 重复检测每一份都能勾选：「建议保留」的可以手动改选删除，「建议删除」的默认勾上
- 勾上建议保留项时同组其余自动取消勾选，每组始终至少保留一份
- 新增「批量删除所选」，一次处理所有勾选项
- 「忽略这组」改为持久生效，扫描后不再自己冒出来，并可随时恢复

## 1.1.0

- 设置页新增大模型配置：OpenAI Chat Completions、OpenAI Responses、Anthropic Messages
- 支持 API 地址、模型 ID、Token、超时和连接测试
- Token 保存在 `data/ai-token`（0600），不进入数据库

## 1.0.0

首个公开版本。

- 歌词抓取、审查、内嵌与 `.lrc` 写入
- MusicBrainz 标签刮削、逐字段对照、冲突处理、自动扫描
- AcoustID 指纹兜底
- FLAC / MP3 / OGG / Opus 字节级写入
- 按标签整理、空目录清理、预览与撤销
- 重复音频分类、分类过滤、分类全选与一键删除
- 回收站、写入/改名/整理日志、批量撤销
- API Token、移动端适配、深浅色主题
- Docker 多架构镜像、GitHub Actions、文档站
